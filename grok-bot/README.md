# Grok Bot (xAI) edition

The same team, loaded into **Grok Bot** instead of Better than GrokBot. The charters, skills, routines and data contract are identical. Only the loading is different.

**Use Better than GrokBot if you can.** It installs from a link. Grok Bot has no bundle importer, so each Bot is set up by hand in its app. And Grok gives **one persistent computer per user, not per Bot**: every Bot in Chris's Grok account shares files, browser sessions and logins. That's why:
- the CFO should live in a **separate Grok account**, or be skipped on Grok
- Chris's Grok account must hold only Chris's systems

Official references:
- https://docs.x.ai/grok-bot/bots
- https://docs.x.ai/grok-bot/skills-routines-and-automations
- https://docs.x.ai/grok-bot/approvals-security-and-privacy

See `INSTALL.md` here for the steps and `manifest.json` for the inventory and approval contract.
